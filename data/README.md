# Data

Download `diabetes_012_health_indicators_BRFSS2015.csv` from the
[Diabetes Health Indicators Dataset](https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset)
on Kaggle and put it in this folder:

```
data/diabetes_012_health_indicators_BRFSS2015.csv
```

The CSV is not part of the repository (about 22 MB). Another location can be
given with `--data PATH` to `train.py` and `eda.py`.
